# Engineer & specialist skills

Per-task workers, dispatched as subagents during sprints. Engine-agnostic at the
top with a Unity overlay underneath (e.g. `gameplay-engineer` +
`gameplay-engineer.unity`).

Planned: `gameplay-engineer`, `ui-engineer`, `backend-engineer`,
`rendering-engineer`, `multiplayer-engineer`, `networking-engineer`,
`tools-build-engineer`, `release-engineer`. (Phase 1+.)
